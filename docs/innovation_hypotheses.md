# 创新假设与可证伪闭环（模板）

> 目的：把“创新点”转化为**可检验假设**与**系统级消融**，并对应具体指标。

## H1 环境上下文切换（Context）
- 假设：在高阴影衰落或环境扰动场景中，启用环境上下文切换可提升 PDR 且不显著增加能耗。
- 机制路径：环境状态 → CAS 阈值/模式切换 → 路由决策调整。
- 关键指标：PDR、能耗/成功包、延迟（如声明）。
- 消融：`disable_context=true`
- 成功判据：CI 不跨 0 且效应量方向一致（阈值待定）。

## H2 Skeleton 骨干路由
- 假设：骨干结构可降低长链路失败率与控制开销。
- 机制路径：骨干结构 → CH‑to‑BS 路径稳定性 → 控制报文减少。
- 关键指标：PDR、控制开销（包数/字节）、能耗。
- 消融：`disable_skeleton=true`

## H3 Gateway 协作/安全平面
- 假设：协作网关与安全钩子提升可靠性，但存在可控的能耗开销。
- 机制路径：多路径/协作转发 → 端到端可靠性提升。
- 关键指标：PDR、能耗/成功包、失败模式统计。
- 消融：`disable_gateway=true`, `disable_safety=true`

---

## 统一消融报告要求
- 每个消融必须输出：均值、95% CI、效应量、p 值（多重校正）。
- 必须在 `docs/claims_to_evidence_table.md` 中登记证据链。
