## 一、能量模型公式检查

### ✅ 公式正确性验证

#### 公式1-3: 传输能量模型 ✓

**论文公式** (Line 282-292):
```latex
E_{tx}(k, d, P_{tx}) = k \cdot E_{elec}^{tx} + k \cdot \frac{P_{tx}}{\eta_{amp}} \cdot f(d)

f(d) = {
  d^2,  d ≤ d_0
  d^4,  d > d_0
}

d_0 = 87m (for h_t = h_r = 1.5m at 2.4GHz)
```

**理论依据**: Two-ray ground reflection model
- **自由空间损耗**: $P_r \propto 1/d^2$ when $d < d_0$
- **地面反射影响**: $P_r \propto 1/d^4$ when $d > d_0$
- **交叉距离**: $d_0 = \frac{4\pi h_t h_r}{\lambda}$

**验证计算**:
```python
lambda_2.4GHz = 3e8 / 2.4e9 = 0.125m
d_0 = 4 * π * 1.5 * 1.5 / 0.125
    = 4 * 3.14159 * 2.25 / 0.125
    = 226.19m
```

**⚠️ 问题发现**: 论文声称$d_0 = 87$m，但理论计算为226m！

**原因分析**: 
- 可能使用了不同的天线高度
- 或者参考了不同的文献公式

**建议修正**:
```latex
Option 1: 修正为理论值
d_0 = 226m (for h_t = h_r = 1.5m at 2.4GHz)

Option 2: 保留87m但说明来源
d_0 = 87m (empirically calibrated for CC2420, following [Heinzelman2000LEACH])

Option 3: 使用简化模型
Use simplified d^2 model only, as CC2420 typical range < 100m
```

#### 公式4-5: 接收和总能量 ✓

**论文公式** (Line 304-313):
```latex
E_{rx}(k) = k \cdot E_{elec}^{rx}

E_i^{total}(t) = Σ_{j∈Tx_i(t)} E_{tx}(k_j, d_{ij}, P_{tx}) + 
                  Σ_{j∈Rx_i(t)} E_{rx}(k_j) + 
                  E_{idle}(t)
```

**验证**: 
- 单位一致性: nJ/bit × bits = nJ ✓
- 累加逻辑正确 ✓
- 空闲能耗考虑: $E_{idle} = P_{idle} \cdot T_{idle}$ ✓

**参数合理性检查**:
| 参数 | 论文值 | CC2420 datasheet | 评价 |
|-----|--------|------------------|------|
| $E_{elec}^{tx}$ | 208.8 nJ/bit | ~208 nJ/bit @ 250kbps | ✓ 准确 |
| $E_{elec}^{rx}$ | 225.6 nJ/bit | ~225 nJ/bit @ 250kbps | ✓ 准确 |
| $P_{idle}$ | 426 μW | 426 μW (idle mode) | ✓ 准确 |

**结论**: 能量参数校准准确，符合CC2420规格书 ✓

## 二、信道模型公式检查

### ✅ 路径损耗模型 ✓

#### 公式6-7: Log-normal shadowing (Line 328-336)

**论文公式**:
```latex
P_{rx}(d) = P_{tx} - PL(d)

PL(d) = PL(d_0) + 10·n·log10(d/d_0) + X_σ

其中:
- PL(d_0) = 40 dB at d_0 = 1m
- n = 2.8 (Intel Lab office)
- X_σ ~ N(0, σ^2), σ = 7.5 dB
```

**理论验证**:
- **自由空间路损** ($n=2$): $PL = 20\log_{10}(d) + 20\log_{10}(f) - 147.55$
- **1m参考**: 对于2.4GHz, $PL(1m) = 20\log_{10}(2.4 \times 10^9) - 147.55 = 40.6$ dB ✓

**参数合理性**:
| 环境 | 论文$n$ | 文献典型值 | 论文$\sigma$ | 文献典型值 | 评价 |
|-----|--------|-----------|-------------|-----------|------|
| Office | 2.8 | 2.6-3.0 | 7.5 dB | 5-10 dB | ✓ 合理 |
| Residential | 3.0 | 2.8-3.2 | - | 4-8 dB | ✓ 合理 |
| Open | 2.2 | 2.0-2.5 | 4.0 dB | 3-5 dB | ✓ 合理 |
| Corridor | 1.8 | 1.6-2.0 | 3.5 dB | 3-4 dB | ✓ 合理 |

**引用支持**: 
- Rappaport (2015) ✓
- Srinivasan & Levis (2008) ✓
- Zhao & Govindan (2003) ✓

### ✅ 包接收概率模型 ✓

#### 公式8: Sigmoid函数 (Line 341-343)

**论文公式**:
```latex
P_{success}(P_{rx}) = 1 / (1 + exp(-(P_{rx} - P_{sens})/δ))

其中:
- P_{sens} = -94 dBm (CC2420 sensitivity @ 1% PER)
- δ = 3 dB (transition width)
```

**理论基础**: 
- **Sigmoid模型**: 广泛用于WSN链路质量建模
- **物理意义**: $\delta$代表从可靠接收到完全丢失的过渡区间

**参数验证**:
```python
# CC2420 sensitivity from datasheet
P_sens_typical = -95 dBm @ 1% PER
P_sens_paper = -94 dBm  # Slightly conservative, acceptable

# Transition width: 3dB means 90% confidence interval spans 6dB
# Typical for IEEE 802.15.4: 2-5 dB ✓
```

**结论**: 参数选择合理且偏保守，有利于现实部署 ✓

#### 公式9: LQI映射 (Line 346-348)

**论文公式**:
```latex
LQI(P_{rx}) = 50 + 6·(P_{rx} + 95)

线性映射 P_{rx} ∈ [-95, -85] dBm → LQI ∈ [50, 110]
```

**CC2420规格验证**:
- CC2420 LQI范围: 0-255 (8-bit)
- 但实际有效范围: 50-110 ✓ （匹配论文）
- 线性映射斜率: $(110-50)/((-85)-(-95)) = 6$ dB^-1 ✓

**⚠️ 潜在问题**: 
- 公式假设线性关系，但CC2420实际LQI可能非线性
- 建议添加注释说明这是简化模型

## 三、优化模型公式检查

### ⚠️ 多目标优化问题 (Line 370-378)

**论文公式**:
```latex
min  Σ E_i^{total}(t)        (minimize total energy)
max  PDR                      (maximize reliability)
max  F                        (maximize fairness)

s.t.  E_i(t) ≥ 0, ∀i,t
      P_{tx} ∈ [-25, +3] dBm
      Each packet transmitted at most once per round
```

**⚠️ 问题1: 多目标优化方法未明确**

**现象**: 
- 声称"multi-objective optimization"
- 但未说明如何权衡三个目标
- 实际使用的是加权和方法（Line 410）

**建议修正**:
```latex
Option 1: 承认使用加权标量化
min  Σ E_i^{total}(t) - λ_PDR·PDR - λ_F·F

Option 2: 声明Pareto优化
Minimize (E_total, -PDR, -F) in Pareto sense,
approximated via weighted sum: ...
```

**⚠️ 问题2: 约束不完整**

**缺失约束**:
1. **连通性约束**: 至少一条路径到BS
2. **能量约束**: $E_i(t) \geq E_{min}$（最小运行能量）
3. **簇大小约束**: $n_{cluster} \in [n_{min}, n_{max}]$
4. **公平性约束**: $\mathcal{F} \geq \mathcal{F}_{threshold}$

**建议添加**:
```latex
Additional constraints:
- Network connectivity: ∃ path from each node to BS
- Minimum operational energy: E_i(t) ≥ 0.1J
- Cluster size bounds: 3 ≤ n_cluster ≤ 15
- Fairness threshold: F ≥ 0.7
```

### ⚠️ 奖励函数 (Line 409-411)

**论文公式**:
```latex
r = -E_{consumed} + λ_PDR·PDR + λ_fairness·F

其中:
- λ_PDR = 10
- λ_fairness = 5
```

**⚠️ 问题3: 量纲不一致**

**分析**:
```
E_consumed: 单位 mJ (milli-Joules)
PDR: 无量纲 [0, 1]
F: 无量纲 [1/N, 1]

奖励: r = -mJ + 10·[0,1] + 5·[0,1]
         = -mJ + [0, 15]
```

**问题**: 
- 能量项单位为mJ，范围通常0.1-10 mJ per round
- PDR和F项范围为0-15
- **能量项的影响被PDR/F项淹没**！

**建议归一化**:
```latex
r = -E_{consumed}/E_{ref} + λ_PDR·PDR + λ_fairness·F

其中 E_{ref} = 1.0 mJ (reference energy per round)

或者使用无量纲形式:
r = -(E/E_max) + λ_PDR·PDR + λ_fairness·F
```

**⚠️ 问题4: 权重选择缺乏justification**

**现象**: 
- $\lambda_{PDR} = 10$, $\lambda_{fairness} = 5$
- 为什么PDR重要性是能量的10倍？
- 为什么PDR是Fairness的2倍？

**建议**: 
1. 提供权重选择的sensitivity analysis
2. 或者引用相关文献支持这个选择
3. 或者承认这是empirical tuning结果

## 五、统计公式检查

### ✅ Jain's Fairness Index ✓ (Line 363-366)

**论文公式**:
```latex
F = (Σ E_i^{total})^2 / (N·Σ (E_i^{total})^2)

F ∈ [1/N, 1], F=1 indicates perfect fairness
```

**验证**:
- **定义正确**: 标准Jain's index ✓
- **范围正确**: 
  - 最不公平（1个节点消耗全部）: $F = 1/N$ ✓
  - 最公平（所有节点相等）: $F = 1$ ✓

---

### ✅ Cohen's d Effect Size ✓ (引用但未给公式)

**标准公式**:
```latex
d = (μ_1 - μ_2) / s_pooled

s_pooled = sqrt[(s_1^2 + s_2^2) / 2]
```

**论文声称**: Cohen's $d = 1.89$ (large effect)

**解释**:
- $|d| < 0.5$: small
- $0.5 \leq |d| < 0.8$: medium
- $|d| \geq 0.8$: large ✓

**建议**: 在Statistical Methodology章节补充Cohen's d公式定义

```
Transmission time: 8192 / 250,000 ≈ 33 ms

Round duration: 30-60 seconds (paper)

```

**结论**: 参数选择自洽且合理 ✓
