1. **Tang, J., Gu, X., Huang, X., et al. (2025). Enhancing Underwater Wireless Sensor Network Lifetime: An Energy-Aware AUV-Assisted Data Collection Scheme. _IEEE Sensors Journal, 25_(15), 29953–29965. https://doi.org/10.1109/JSEN.2025.3580629**  
   摘要：提出能量感知的AUV辅助数据汇集方法，通过路径规划与功率调度降低水下WSN能耗；在不同节点密度下验证网络寿命与采集成功率提升。方法基于分层调度+链路质量评估，兼顾航行成本与节点剩余能量。实测显示相较传统轮询方案，寿命提升15–25%，PDR稳定在0.9以上，适合稀疏、水声高衰减场景。  
   标签：水下WSN，能量优化，移动汇聚，路径规划  
   相关性：★★★★★

2. **Ogundile, O., Babalola, O., Agboola, E., et al. (2025). Path Priority Routing Protocol for Underwater Wireless Sensor Network. _IEEE Internet of Things Journal, 12_(15), 31654–31668. https://doi.org/10.1109/JIOT.2025.3574076**  
   摘要：提出基于路径优先级的水下路由协议，综合链路质量、能量与跳数打分，动态更新优先队列以适应水声链路时变。仿真与池塘实验显示在高误码和节点稀疏场景下，PDR较传统矢量路由提升8–12%，能耗降低约10%。对AERIS的Gateway/Skeleton可提供水下版启发。  
   标签：水下WSN，鲁棒路由，链路评分，时变信道  
   相关性：★★★★☆

   标签：定位，稀疏重建，多源估计，鲁棒性  
   相关性：★★★★☆
