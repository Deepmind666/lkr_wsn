# GPT DeepSearch 深度研究任务

## 研究背景

AERIS是一个WSN路由协议，包含三个模块：
- CAS (Context-Adaptive Switching): 自适应选择DIRECT/CHAIN/TWO_HOP模式
- Gateway: 选择关键节点优化上行链路
- Skeleton: 构建骨干网络

消融实验(1600任务)显示异常：Gateway有效(p=8.49e-29)，但CAS和Skeleton无效甚至负面。
