## ✅ 格式修正详情

### 修正内容

**修正项目**: 页码连字符统一  
**修正前**: 18处使用单连字符"-"  
**修正后**: 全部改为双连字符"--"  
**修正方法**: PowerShell正则替换

### 修正命令

```powershell
(Get-Content bibliography.bib) -replace 'pages = \{(\d+)-(\d+)\}', 'pages = {$1--$2}' | Set-Content bibliography.bib
```

### 验证结果

```powershell
Select-String -Pattern "pages = \{\d+-\d+\}" bibliography.bib | Measure-Object
# 结果: 0 (无单连字符，修正成功)
```

## 📋 使用指南

### 如何使用生成的文献库

#### 1. LaTeX编译使用

```latex
% 在main.tex中引用
\bibliographystyle{mdpi}  % 使用MDPI样式
\bibliography{bibliography}  % 引用bibliography.bib

% 文中引用示例
LEACH协议\cite{Heinzelman2005Energy}首次提出...
我们使用Welch's t检验\cite{Welch1947}进行统计分析...
```

#### 2. 查阅摘要翻译

```bash
# 打开摘要翻译文档
docs/Bibliography_Abstracts_CN_Complete.md

# 按Ctrl+F搜索文献关键词
例如：搜索"MeFi"找到对应翻译
```

#### 3. 核对引用编号

```bash
# 打开格式核对报告
docs/Bibliography_Format_Check_Report.md

# 查看各类别文献编号范围
[1]–[10]: 2024-2025最新文献
[11]–[15]: 经典协议
[31]–[33]: 统计方法
```

#### 4. 补充新文献

```bibtex
% 在bibliography.bib末尾添加
@article{NewPaper2025,
  title = {新论文标题},
  author = {作者},
  journal = {期刊名},
  volume = {卷号},
  pages = {起始--结束},  % 注意使用--
  year = {2025},
  doi = {10.xxxx/xxxxx}
}
```
