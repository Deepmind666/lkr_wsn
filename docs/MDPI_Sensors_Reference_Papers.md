## 🎯 学习重点（提升写作水平）

### 从这些MDPI Sensors论文中学习：

#### 1. Abstract写法
- **结构**: Background → Methods → Results → Conclusions
- **长度**: 150-200词
- **关键数字**: 必须包含主要性能提升数据
- **示例**（Tariq 2024）:
  > "...our RWSN design相比基线方法显著提高了网络寿命..."

#### 2. Introduction结构
- **段落1**: 领域背景和重要性
- **段落2**: 现有方法的局限性
- **段落3**: 研究动机和gap
- **段落4**: 本文贡献（Contributions列表）
- **段落5**: 论文组织结构

#### 3. Related Work组织
- **按主题分类**（不是按时间）
  - Classical Protocols
  - Machine Learning Approaches
  - Energy Harvesting
  - Security-aware Routing
- **每个小节**:
  - 先综述该主题
  - 引用3-5篇代表性工作
  - 指出不足
  - 说明本文如何改进

#### 4. 实验部分规范
- **Table 1**: Simulation Parameters（必须有）
- **Table 2**: Performance Comparison
- **每个Figure**: 
  - 必须在正文中引用
  - Caption要自解释（self-contained）
  - 包含统计信息（error bars, confidence intervals）

#### 5. 数学公式规范
- **编号**: 所有重要公式都要编号
- **符号表**: 复杂论文需要Nomenclature表
- **解释**: 公式后立即解释所有变量

#### 6. Discussion vs Results
- **Results**: 呈现数据，客观描述
- **Discussion**: 
  - 解释为什么会有这样的结果
  - 机制分析
  - 与理论预期对比
  - 局限性和威胁
