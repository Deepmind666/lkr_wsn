# 数据 Schema（统一字段与单位）

> 目的：统一多数据源的字段语义，明确“测量值 vs 模拟值”。

## 必选字段
| 字段 | 含义 | 单位 | 类型 | 来源 | 备注 |
|---|---|---|---|---|---|
| node_id | 节点编号 | - | int | 原始数据/模拟 | - |
| timestamp | 时间戳 | s | float | 原始数据 | 若无，使用索引并注明 |
| x, y, z | 坐标 | m | float | 原始数据/模拟 | 若无，说明构造方法 |
| temp | 温度 | °C | float | 测量 | 缺失则留空 |
| humidity | 湿度 | %RH | float | 测量 | 缺失则留空 |

## 可选字段（链路质量）
| 字段 | 含义 | 单位 | 类型 | 来源 | 备注 |
|---|---|---|---|---|---|
| rssi | 接收信号强度 | dBm | float | 测量/模拟 | 说明转换方法 |
| lqi | 链路质量指标 | - | float | 测量/模拟 | 说明范围 |
| snr | 信噪比 | dB | float | 测量/模拟 | 说明计算方式 |

## 模拟字段
| 字段 | 含义 | 单位 | 类型 | 备注 |
|---|---|---|---|---|
| pdr | 端到端投递率 | 0-1 | float | 由模拟计算 |
| energy_j | 能耗 | J | float | 统一能耗模型 |
| delay_ms | 时延 | ms | float | 若未测量则禁用 |

## 约定
1. 必须标注哪些字段是“测量值”，哪些是“模拟值/映射值”。
2. 数据集如无坐标/链路质量，必须在实验设置中解释构造方法及局限性。
