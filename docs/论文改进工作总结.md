### 2. **数学公式与代码参数不一致**

#### 能量模型
**修正前**：
```latex
E_tx = E_elec * k + epsilon_amp * k * f(d)
E_elec = 50 nJ/bit (通用值)
epsilon_amp = 10 pJ/bit/m^2 (自由空间)
```

**修正后（与CC2420代码一致）**：
```latex
E_tx = 208.8 * k + E_amp(d, P_tx) * k  (nJ)
E_amp = (P_linear / 0.5) * {d^2 * 1e-9 or d^4 * 1e-12}
E_rx = 225.6 * k (nJ/bit)
```

#### 信道模型
**修正前**：
- Path loss exponent: 2.8 (office), 3.0 (residential)
- Shadowing std: 7.5 dB (Intel Lab)

**修正后（与代码一致）**：
- n = 2.0 (office), 1.8 (residential), 2.1 (outdoor)
- σ = 4.5 dB (office), 3.5 dB (residential), 4.0 dB (outdoor)
